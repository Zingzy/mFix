# Getting help

**Something is broken.** Open a bug report from the Issues tab. Include your macOS version, your mFix version (select mFix in Applications and press Cmd+I), and your displays.

**A shortcut does nothing.** Check Accessibility in System Settings, Privacy & Security. If mFix is listed and on, remove it with the minus button and add it again. Then quit any other window manager or switcher, like Rectangle or AltTab. Two apps can't hold the same shortcut.

**The switcher has no thumbnails.** Check Screen Recording in the same place.

**Cmd+Tab stopped working after mFix quit.** Open mFix again and quit it from its menu. It puts back the system shortcuts it turned off. If that doesn't help, open an issue.

**An idea or a question.** Start a thread in Discussions. Feature requests are welcome as issues too. Tell us what Windows does and what macOS does today.

**A security problem.** See [SECURITY.md](SECURITY.md). Don't post it publicly.
